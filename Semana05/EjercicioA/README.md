# Clínica Salud+

Aplicación Android desarrollada con Kotlin y Jetpack Compose que permite consultar médicos por 
especialidad, revisar sus perfiles, agendar citas y consultar las reservas e historial médico.

## Requerimientos funcionales

1. **Consultar médicos:** mostrar una lista de especialistas con nombre, especialidad y calificación, y permitir filtrarlos por especialidad.

2. **Visualizar el perfil del médico:** mostrar la información del especialista seleccionado, incluyendo experiencia, descripción y calificación, con un botón para agendar una cita.

3. **Agendar una cita:** permitir seleccionar una sola fecha y una sola hora entre las opciones disponibles, registrar la reserva y mostrar una confirmación con los datos elegidos.

4. **Consultar citas e historial:** permitir navegar mediante un menú lateral a Mis citas e Historial médico, diferenciar las citas confirmadas de las completadas y mostrar las atenciones completadas en el historial.
